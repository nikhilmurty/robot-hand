# Hardware

This folder contains all the files for printing the hand as well as all of the fingers. Follow the link to this [onshape file](https://cad.onshape.com/documents/e974f0bc1062bd7b6ade647d/w/e4fd7f55056d36383327a202/e/fd9bded8c1b01162ac553002?renderMode=0&uiState=6a4c9dbf046b862a1ab126a8) to see how it should look:



## Parts
You will also need to obtain:

- 5 Dynamixel XL-330 motors
- 30 Bearings with dimensions 5mm ID, 8mm OD (I used MR85-2RS)
- 15 M5 x 14 Dowel pins
- Durable cable (I used a braided fishing line rated for 40 lbs)
- 5 0.5 x 5.5 x 35.5 mm springs for tensioning
